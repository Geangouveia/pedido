# PEDIDO 

Recentemente correu pelas redes sociais programadores fazendo seus pedido, sendo que só é possivel clicar sobre o botão SIM, pois ao passar o mouse encima do NÃO, ele vai para um lugar aleatorio na tela, fazendo com que a vitima tenha apenas uma unica opção que é aceitar.

Este código fonte possui uma versão desse aplicativo feita em HTML
